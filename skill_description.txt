# スキル名

以下の命名規則に従って、
スキル名を生成してください。


## 命名規則

{対象業務}-{処理内容}


## 命名条件

1. 英小文字を使用してください。

2. 単語の区切りにはハイフンを使用してください。

3. 空白や日本語を使用しないでください。

4. スキルの用途が名称から分かるようにしてください。

5. エージェント指示の
   `target-skill-name` と一致させてください。


## 命名例

mhlw-paid-leave-search

hr-work-rules-search

it-security-policy-search


# スキルの説明

以下の構成に従って、スキルの説明を生成してください。


## 使用条件

{対象業務}に直接関連する質問の場合に使用するスキルであることを記述してください。


## 対応範囲

以下の質問や業務に使用することを記述してください。

- {対象となる質問例1}
- {対象となる質問例2}
- {対象となる質問例3}
- {対象となる質問例4}


## 対象外

以下の質問や業務には使用しないことを記述してください。

- {対象外となる質問例1}
- {対象外となる質問例2}
- {対象外となる質問例3}


# 記述ルール

1. スキルの説明は簡潔に記述してください。

2. スキルを使用する条件と、使用しない条件を明確にしてください。

3. 具体的な処理手順は記述しないでください。

4. Knowledge検索の詳細な手順は、スキル指示に記述してください。

5. 対象範囲と対象外の条件が矛盾しないようにしてください。


# 出力形式

以下の2つを出力してください。

1. スキル名

2. スキルの説明

スキル名と説明は、Copilot Studioの各入力欄へそのまま貼り付けられる形式にしてください。
