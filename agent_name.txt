# 目的

Microsoft Copilot Studioで作成する
AIエージェントの名称を生成してください。

エージェントの利用目的と対象業務が、
名前から分かるようにしてください。


# 命名ルール

1. エージェントの担当業務を明確にしてください。

2. 必要に応じて、
   使用する情報源や処理内容を名称に含めてください。

3. 一般の利用者が理解できる名称にしてください。

4. 不必要に長い名称にしないでください。

5. 他のエージェントと区別しやすい名称にしてください。

6. エージェント名には、
   原則として「エージェント」を含めてください。


# エージェント名の構成

以下の構成を基本としてください。

{対象業務または情報源}{主な処理}エージェント


# 命名例

厚労省有給休暇検索エージェント

社内就業規則検索エージェント

情報セキュリティ規程検索エージェント

経費精算支援エージェント


# 出力形式

作成したエージェント名を
1つだけ出力してください。

名称の理由や補足説明は不要です。
